PUBLICATION.md record publication and Palomar history through the dated
prose-correction preparation checkpoint.

  prose reviews and the original Library archive describe local preparation
  before publication. Their no-public-action statements and quoted README
  passages are historical. The independent review reports are retained
  unchanged rather than rewritten to reflect later events.
- `compatibility-findings.md` and `compatibility-packaging-review.md` describe
  the comparator schema repair before its hosted replay and first Palomar
  intake. That repair was published at

- `validation-manifest.json` identifies the exact current correction's local
  validation boundary and file hashes. Its local logs use macOS unsandboxed
  replay; successful sandboxed Linux runs are separate GitHub artifacts linked
  from the publication record.
